New findings (not in the handoff)

research_loop.py has three divergent copies and no drift guard. Canonical (dragan-plugins), the production fork that actually emails you (demo-autonomous-research-loop — deliberately forked for Max/ZAI backend selection, no mechanism ports upstream fixes), and a frozen demo_factory snapshot. This exact pattern is why the T6 bug kept shipping after it was "fixed." Options: (a) a periodic diff-check timer, (b) refactor the fork to import shared core the way graph_eight already does (recommended — working precedent in-estate), (c) accept recurrence.
Zero-tool-call empty completions on the YouTube lane. Two of four re-POSTed runs launched correctly and then did literally nothing (0 tool calls, complete-no-error, ~30s). Not the old fire-and-forget bug — new, and now visible because the gate + classification work. Needs its own investigation (coordinator/GLM behavior? degenerate prompt with empty title?).
Deploy trains strand queued hook runs. Each merge's deploy restarts the gateway; a queued-but-unclaimed run rides out restarts as an orphan until the 60-minute reaper. Worked as designed here, but batching merges before dispatching long agent runs is the operational lesson (self-inflicted twice today).
Digest inclusions are never marked emailed (only the wrapping daily_digest artifact gets a delivery record) — once #1622 starts surfacing the 3,436-artifact backlog, the same candidate can repeat across days until reviewed. Candidate follow-up ticket.
CI never runs the CSI test suite. pr-validate.yml runs repo-root tests/unit only; the 40+ test files under CSI_Ingester/development/tests/ are invisible to CI (pre-existing).
Two tests/gateway notification-cooldown tests fail on origin/main itself (not in the CI gate, pre-existing; verified by stash).
Agent-fleet gotcha: harness worktrees are auto-removed the instant their branch merges — killing any local test run still in flight with a distinctive FileNotFoundError-then-collection-errors signature. CI on the merged tree is the honest check; expect and ignore this local pattern.
